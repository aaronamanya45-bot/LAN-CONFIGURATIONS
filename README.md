# Network Configuration Commands

This repository contains common commands used when configuring, testing, monitoring and troubleshooting computer networks.

The commands are grouped into different sections so that students can easily learn them and practice them.

## Topics Covered

1. Basic Network Commands
2. IP Addressing Commands
3. Windows Network Commands
4. Linux Network Commands
5. Cisco Router and Switch Commands
6. VLAN Commands
7. Routing Commands
8. DHCP Commands
9. DNS Commands
10. Network Testing Commands
11. Network Troubleshooting Commands

## Important Note

Some commands require Administrator or Root privileges.

The exact commands available can also depend on the operating system or networking device being used.

## Basic Network Configuration Process

A simple network configuration normally involves:

```text
1. Connect the device
       ↓
2. Configure the IP address
       ↓
3. Configure subnet mask
       ↓
4. Configure default gateway
       ↓
5. Configure DNS
       ↓
6. Test connectivity
       ↓
7. Troubleshoot if necessary
```

## Common Commands

| Command      | Purpose                                 |
| ------------ | --------------------------------------- |
| `ipconfig`   | Displays Windows IP information         |
| `ifconfig`   | Displays Linux interface information    |
| `ip addr`    | Displays IP addresses on Linux          |
| `ping`       | Tests connectivity                      |
| `tracert`    | Traces a route on Windows               |
| `traceroute` | Traces a route on Linux                 |
| `nslookup`   | Checks DNS information                  |
| `arp`        | Displays ARP information                |
| `route`      | Displays or changes routing information |
| `netstat`    | Displays network connections            |
| `hostname`   | Displays the computer name              |

## Learning Goal

The purpose of this repository is to provide a simple reference for students learning computer networking and network configuration.
